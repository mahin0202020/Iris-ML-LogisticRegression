# Iris-ML-LogisticRegression
 

This project is a simple Machine Learning project on the **Iris dataset** using Python.

## Features

- Logistic Regression for multi-class classification
- Target encoding (setosa=1, virginica=2, versicolor=3)
- Scatter plot visualization for Sepal Length vs Sepal Width
- Confusion matrix heatmap for model evaluation
- Train/Test split and accuracy calculation

## Files

- `iris_logistic_regression.ipynb` → Jupyter Notebook with complete code

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- kagglehub (for dataset download)
